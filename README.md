## 🔥 Основные проекты

### 🎮 Obsession of Fear  
*Психологический хоррор без монстров* (в разработке, релиз ~конец августа 2026)

- **Движок:** Unity 6, C# (Built‑in RP)  
- **Концепт:** FPP, главный герой в квартире, угроза — деградирующая психика (Sanity/Paranoia)  
- **Геймплей:** цикл пивоварения, продажи через in‑game мессенджер, система статов  
- **Реализовано:** полный цикл варки, заказы, доставка, магазин, PBR‑текстуры, оптимизация (Static Batching + light baking)  
- **В плане:** 4 ветки апгрейдов, сохранения, ночь с фонариком, несколько концовок

> [Подробнее о проекте →](https://github.com/TsDead/obsession-of-fear) *(ссылка появится позже)*

### 🤖 YFB Store — Telegram Mini App  
*Живой магазин одежды с автоимпортом из канала*

- **Заказчик:** @YFBstore  
- **Стек:** FastAPI, aiogram, React, TypeScript, Tailwind, SQLite, Docker  
- **Особенности:**  
  - Парсинг постов (словари брендов/категорий, отслеживание «продано»)  
  - Поиск по кириллице (search_text)  
  - Оформление заказов, интеграция с доставкой  
  - Полный CI/CD на Amvera PaaS  
  - 110 тестов, headless‑отладка WebView через Puppeteer

> [Попробовать →](https://t.me/YFBstore_bot) (Mini App внутри бота)
